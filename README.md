This project was built with a modern, lightning-fast frontend stack: **React 18, Vite, TypeScript, Tailwind CSS, shadcn/ui**, and **Recharts**. 

Want to run the tracker on your own machine? It takes less than a minute.

```bash
# 1. Clone the repository
git clone [https://github.com/yourusername/python-mastery-tracker.git](https://github.com/yourusername/python-mastery-tracker.git)

# 2. Navigate into the directory
cd python-mastery-tracker

# 3. Install dependencies
npm install

# 4. Start the Vite development server
npm run dev
